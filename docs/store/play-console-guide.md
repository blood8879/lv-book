## 1. 데이터 보안 (Data safety)

### 핵심 판단 기준
Play의 데이터 보안에서 "수집(collection)"은 **데이터가 기기 밖(개발자 또는 제3자 서버)으로 전송될 때**를 의미합니다. 기기 안에서만 처리·저장되고 전송되지 않는 데이터는 신고 대상이 아닙니다.

### 항목별 답변

| 데이터 유형 | 수집? | 근거 / 처리 방식 |
|---|---|---|
| **광고 ID(Advertising ID)** | **예 — 수집·공유** | Google AdMob이 광고 게재를 위해 기기 광고 ID 등 식별자를 수집. 제3자(Google)와 공유됨 |
| **기기/기타 식별자** | **예(광고 목적)** | AdMob이 광고 게재·측정에 사용 |
| **정확한 위치(위도/경도)** | **아니요(미수집)** | BM 좌표 기록용으로만 쓰고 **기기 로컬 SQLite에만 저장, 전송 없음** → Play 정의상 미수집 |
| **사진** | **아니요(미수집)** | BM 사진은 기기에만 저장, 전송 없음 |
| **야장/측량 데이터, 프로젝트, 개인 메모** | **아니요(미수집)** | 전부 기기 로컬 저장, 클라우드·서버 전송 없음 |
| **구매 내역** | **아니요(앱 미수집)** | 인앱 결제는 Google Play 결제 시스템이 처리. 앱은 구매 영수증을 서버로 보내지 않고 로컬에서 Pro 상태만 확인 |
| **이름/이메일/전화번호/계정** | **아니요** | 회원가입·로그인 없음 |

### 수집한 데이터(광고 ID)에 대한 후속 질문
- **수집 목적**: 광고 게재(Advertising or marketing) — 제3자 광고 네트워크(AdMob)
- **제3자와 공유되나요?**: **예** (Google/AdMob)
- **전송 중 암호화되나요?**: **예** — AdMob 통신은 HTTPS로 암호화됩니다
- **사용자가 데이터 수집을 선택 해제(삭제 요청)할 수 있나요?**: 앱은 서버에 데이터를 보관하지 않으므로 별도 삭제 요청 창구가 없습니다. **앱을 삭제하면 기기 내 모든 데이터가 함께 삭제**됩니다. 광고 개인화는 기기의 광고 설정(광고 ID 재설정/삭제)에서 사용자가 제어할 수 있습니다.
- **이 데이터가 앱 기능에 필수인가요?**: 광고 ID 수집은 무료(광고) 이용에 수반됩니다. Pro 구매 시 광고가 제거됩니다.

> **요약 신고안**: 데이터 보안에서 신고할 항목은 사실상 **광고 ID(수집·제3자 공유·광고 목적)** 하나입니다. 위치·사진·야장 데이터는 로컬 전용이므로 미수집으로 신고합니다.
