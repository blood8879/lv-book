# Handoff: 레벨 야장 (Lv Book) — UI 리디자인

## Overview
직접수준측량 야장 기록 앱 "레벨 야장(Lv Book)"의 전면 UI 리디자인. 토목·건축 현장에서 야장을 오프라인으로 기록하고 IH(기계고)/GH(지반고)/폐합오차를 자동 계산해 제출용 PDF/CSV로 내보내는 Flutter 모바일 앱(v1.1.0, Android 우선, iOS 지원). 이 패키지는 전 화면(핵심 야장 편집 3안 포함) + 다크모드 + PDF 출력물 + 공통 상태의 하이파이 디자인 참조를 담습니다.

## About the Design Files
이 번들의 파일은 **HTML로 만든 디자인 레퍼런스**입니다 — 의도한 룩앤필과 동작을 보여주는 프로토타입이며, 그대로 복사해 배포하는 프로덕션 코드가 아닙니다. 실제 구현 대상은 **기존 Flutter 코드베이스(Material 3)** 이며, 이 HTML 디자인을 Flutter의 확립된 패턴·위젯으로 재현하는 것이 과제입니다. 앱은 이미 기능이 전부 구현·검증된 상태이므로, 이 작업은 **비주얼 레이어 교체**(레이아웃/컬러/타이포/컴포넌트 스타일)이며 정보 구조·데이터·문구는 원본 명세를 따릅니다.

## Fidelity
**High-fidelity (hifi)** — 최종 컬러·타이포·간격·상태가 확정된 목업입니다. 개발자는 아래 디자인 토큰과 화면별 명세를 픽셀 단위로 재현하되, Flutter의 테마 시스템(ThemeData / ColorScheme)과 위젯으로 구현합니다.

단, `레벨야장 와이어프레임.dc.html`은 초기 **low-fidelity 그레이스케일 와이어프레임**(S-04 3안)으로, 구조 탐색 이력용 참고 자료입니다. 최종 기준은 `레벨야장 리디자인.dc.html`입니다.

## 필수 규칙 (임의 변경 금지)
색상 값·폰트·레이아웃은 재량이지만, 아래 의미·표기·원문은 유지합니다.

- **시맨틱 컬러 매핑**: 초록=GH·적합·사용가능 / 파랑=IH·기준점(BM) / 오렌지=TP·주의·Pro·백업 강조 / error(빨강)=차단 오류·사용 중지. **IH와 GH는 반드시 다른 색**(현장에서 열을 색으로 식별).
- **데이터 표기**: 단위 전부 m(미터). 표고·IH·GH·ΣBS·ΣFS·차 = 소수 3자리. 폐합오차(오차) = 소수 4자리(유일). 허용오차 0.001m. 좌표 소수 6자리. 날짜 yyyy-MM-dd, 시각 yyyy-MM-dd HH:mm. 숫자는 tabular numerals.
- **판정 라벨**: '적합' / '확인 필요' 2종만. **'불합격' 금지**. 허용오차 초과를 "오류"로 단정 금지(경고일 뿐, 내보내기 가능).
- **Pro는 '구독' 금지** — 일회성 구매.
- **판정·상태는 색+텍스트 병행** (색맹·흑백 출력 대응).
- 광고 정책 2문구, 연쇄 삭제 경고, BM 재확인 경고, 위치 권한 안내 문구는 원문 유지.

## Screens / Views

### S-04 · 야장 편집 (측정 입력) — ⭐ 핵심 화면, 3개 레이아웃 안
앱의 핵심 가치. "이 측량은 지금 맞게 가고 있나(검산·판정), 다음 입력은 어디인가?"

- **1a 클래식** (`#1a`): 상단 다크 시작표고 바 → 검토정보(ExpansionTile) → 6열 스프레드시트(NO·BS·FS·IH·GH·액션) → 하단 고정 검증바 → 체크뱃지 Wrap → 다크 합계칩(2행 6종). 표가 주인공, 판정 상시 노출.
- **1b 포커스 입력** (`#1b`): 상단 판정 배너 → 컴팩트 4열 표 → 하단 대형 "현재 행" 입력 카드(다크, BS/FS 54px 대형 필드 + 자동 포커스 이동 + ＋10행/다음 버튼). 장갑·엄지존 최적.
- **1c 판정 히어로** (`#1c`): 상단 큰 판정 카드(아이콘 + '적합' + 허용범위 게이지) → 5열 표 → 하단 엄지존 액션바(＋10행 / 저장 / 내보내기=블랙 프라이머리).
- **셀 상태 3종**: 입력가능(잉크) / 읽기전용 IH(파랑 배경) · GH(초록 배경 볼드) / TP 강조행(오렌지 배경). TP 액션셀은 flag(오렌지), 그 외 more_vert.
- **터치 타깃 ≥ 44×44**, 다이내믹 폰트 1.3배까지 표 유지, 고대비(직사광 대응).

### S-01 · 홈 (프로젝트 목록) (`#2a`)
AppBar('레벨 야장' + 설정) → **Pro 다크 패널**(항상 최상단) → 조건부 백업 리마인더(오렌지) → 프로젝트 요약 카드(초록) → 최근 야장 타일(오렌지) → 프로젝트 카드 반복(초록 배지) → **네이티브 광고 카드(저빈도, dashed)** → 하단 배너 광고 → FAB. 리스트 하단 여백 124px(FAB·배너 회피).

### S-02 · 프로젝트 상세 (탭 컨테이너)
AppBar(프로젝트명) + 2탭(description '야장' / pin_drop 'BM 관리'). 탭 인디케이터 잉크색. 순수 컨테이너.

### S-03 · 야장 목록 (`#2b`, dark `#5f`)
검색 필드(포커스=잉크 테두리) → 일괄 내보내기 버튼 → **파랑 배지** 야장 카드(제목 + 'yyyy-MM-dd · 작업구간 · 측량자') → 네이티브 광고 카드(저빈도) → FAB extended('＋ 야장'). 파랑 배지(야장)는 BM 텍스트 배지와 구분.

### S-05 · BM 관리 (`#2c`, dark `#5g`)
텍스트 배지 카드('BM'/'TBM') + **상태 pill(색+텍스트)**: 사용가능=초록 / 훼손의심=오렌지 / 사용중지=error. 사용 중지 카드는 카드 전체를 error 톤으로. 하단 배너 광고 + FAB. 좌표·사진은 목록 미표시(바텀시트에서만).

### S-05a · BM 위치 기록 바텀시트 (`#2d`, dark `#5h`)
드래그핸들 + 종류배지 + 이름 + 'Pro 위치 기록'. **Pro**: 좌표(위도/경도 소수6 + 정확도) + '현재 좌표 저장'/'좌표 복사'/'지도 열기' + 사진 미리보기(높이 120) + 촬영/선택/제거. **비-Pro**: 잠금 업셀 안내만.

### S-06 · 내보내기 (PDF 미리보기) (`#3a`, dark `#5i`)
AppBar('내보내기' + PDF/CSV 공유) + 실시간 PDF 미리보기(surface-soft 배경, 라이트 문서 카드). 저장된 문서 설정 자동 적용. 공유 완료 직후 무료 사용자 전면광고(하루 3회, 10분 간격).

### S-07 · 일괄 내보내기 (`#3b`, dark `#5j`)
비-Pro: 다크 잠금 배너 + dim 처리된 컨트롤(SegmentedButton PDF/CSV/둘다, 체크박스 2개) + 비활성 공유 버튼. Pro+선택 1개 이상일 때만 활성.

### S-08 · 설정 (페이월) (`#3c`, dark `#5c`)
**다크 페이월 패널**(별도 페이월 화면 없음): Pro 아이콘 + 제목 + '₩9,900 · 일회성 구매' + 기능 배지 4개 + 화이트 구매 버튼. → 구매상태 섹션(광고 제거 **읽기전용 스위치**=dim, 구매 복원) → 문서설정(제출용 PDF 설정) → 광고 노출 정책 2문구(원문).

### S-09 · PDF 문서 설정 (`#3d`, dark `#5k`)
전 기능 무료 개방(헤더는 'Pro PDF 설정'). 프리셋 드롭다운 + 3버튼 → 회사명/작성자 → 템플릿/파일명규칙 드롭다운 → 워터마크 → 스위치 2종(검산 판정 표시, 확인 서명란 표시) → 서명 카드(스위치 ON시만) → 파일명 미리보기 → **고정 하단 푸터**(내보내기 이력 / 저장). scroll 영역과 고정 저장 버튼 분리.

### P-01 · PDF 출력물 (A4) (`#4d`) — 라이트 고정
헤더(회사명/작성자 → 제목 '직접수준측량 야장 · 템플릿' → 야장명/날짜 → 시작BM/표고 → 메타데이터) → 7열 표(No/측점명/BS/FS/IH/GH/비고, null='-', TP만 'TP') → 검산 박스(ΣBS·ΣFS·차·시작·최종·오차 + 판정 배지 색+테두리) → 서명란 3칸(작성/검토/승인, 작성칸에 서명 PNG) → 푸터(하단메모 / 페이지번호). **흑백 복합기 대응 — 판정 텍스트 라벨 필수 병기(색은 보조)**. 본문 폰트 NotoSansKR(PDF 전용).

### 공통 상태 (`#4e`, dark `#5n`)
로딩 스켈레톤(리스트/표/PDF 미리보기) · 빈 상태(아이콘 배지 + 제목 + 설명, 일러스트 6종 신규 필요) · 스낵바 3종(성공=초록✓/실패=error✕/진행=스피너, 다크 서피스).

## Interactions & Behavior
- **자동 저장**: 입력 후 900ms 디바운스. 상태 문자열 '저장됨'→'자동저장 대기'→'자동저장됨'. 화면 이탈 시에도 저장.
- **셀 포커스 이동**: BS 확정 → 같은 행 FS → 다음 행 BS + 자동 스크롤.
- **검증 5종**: 첫 BS / 마지막 FS / TP 완성 / 빈 행 / 허용오차. 통과=초록 검증바, 실패=error 배경.
- **내보내기 전 검증**: 차단 오류 → 다이얼로그('확인'만, 진행 불가). 허용오차만 초과 → '취소'/'계속'. 데이터 없음 → 스낵바.
- **폐합오차 판정**: |오차| ≤ 0.001 → '적합'(초록), 아니면 '확인 필요'(error). '확인 필요'여도 내보내기 가능.
- **광고**: 배너=하단 앵커드 적응형(홈·BM목록 2곳). 네이티브 카드=프로젝트/야장 목록 저빈도. 전면=공유 완료 직후(무료, 하루3회·10분간격). **Pro·미지원플랫폼·로딩중엔 배너 영역 높이 0** → 배너 유무 양쪽 레이아웃 모두 대응.
- **다크모드**: 시스템 추종(별도 토글 없음). PDF 출력물(P-01)만 라이트 고정.

## State Management
- 야장 측정 행 배열(측점명·BS·FS·수동TP 플래그), 파생값 IH/GH/합계/폐합오차/판정(계산 로직은 구현됨).
- 자동저장 상태, 검토 상태(작성중/검토완료/확인필요), 검토일/메모.
- Pro 구매 상태(광고 노출·기능 게이팅 분기), 스토어 가격 문자열.
- BM 상태(사용가능/훼손의심/사용중지)·종류(BM/TBM)·좌표·사진.
- PDF 문서 설정(프리셋·회사명·작성자·템플릿·파일명규칙·워터마크·스위치·서명 PNG).
